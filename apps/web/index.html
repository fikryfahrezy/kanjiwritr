Chrome · Edge · Brave

Chromium

ZIP
Download for Chromium ↓
  1. 01

    Download the ZIP above, then extract it to a folder you will keep.

  2. 02

    Open chrome://extensions. Use edge://extensions or brave://extensions in those browsers.

  3. 03

    Turn on Developer mode, choose Load unpacked, and select the extracted folder.

  4. 04

    Open Kanjiwritr from the extensions menu and request a pairing code.

Firefox desktop

Firefox

ZIP
Download for Firefox ↓
  1. 01

    Download and extract the ZIP, then open about:debugging#/runtime/this-firefox.

  2. 02

    Choose Load Temporary Add-on and select manifest.json inside the extracted folder.

  3. 03

    Open Kanjiwritr from the extensions menu and request a pairing code.

  4. 04

    For a permanent install, use the signed XPI when it is available on the latest release.

! Unsigned temporary add-ons are removed when Firefox restarts.
